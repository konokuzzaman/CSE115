# Hospital Management System

Course project for CSE 115.

A console-based hospital management system written in C. It supports user signup/login, an admin panel for managing doctors (add, edit, search, delete), and booking and viewing appointments. Data is stored in local text files.

## How to run

Compile and run on Windows (uses `windows.h`):

```
gcc ARK.c -o ARK
ARK
```
